## Animated heatmap

`flow-heatmap.gif` and `flow-heatmap-static.png` are deterministic diagrams generated by `../scripts/render_heatmap.py` with Pillow. The animation uses a shared color palette and an infinite loop. It illustrates four model calls in a read/create/replace task, reloading rules and memory for every call. It contains no credentials, captured browser UI or live telemetry.

```text
PROJECT RULES + MEMORY → CONTEXT → WEB MODEL
                                      ↓ tool request
                         LOCAL CHECKS → FILE ACTION
                                      ↓
                              BACKUP + AUDIT
                                      ↺ next model call
```

The source script draws text using available system fonts, preferring Segoe UI/Consolas on Windows and DejaVu on Linux. Font files are not distributed.
