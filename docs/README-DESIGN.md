# README design references

Read-only reference review on 2026-10-15. Source structures informed the presentation; their copy, branding and logos were not reused.

| Repository | Stars at review | Pattern applied |
| --- | --- | --- |
| [Ollama](https://github.com/ollama/ollama) | 183,203 | A concise promise followed by runnable getting-started commands |
| [Dify](https://github.com/langgenius/dify) | 158,515 | Repository-local cover image, centered navigation and language switching |
| [Cline](https://github.com/cline/cline) | 70,344 | Concrete tool capabilities and operational explanations |

Star counts were obtained from GitHub's repository API and are a dated snapshot, not a popularity badge for this project.

The result uses English as `README.md` and Traditional Chinese as `README.zh-TW.md`. Both include the same header, animated workflow, commands, constraints and acceptance evidence. The GIF is used because GitHub README content cannot run a custom interactive JavaScript visualization; a static PNG is linked for readers who prefer no motion.

The animation is intentionally marked as schematic. Its component activation schedule explains memory reloads and file-tool cycles; it does not represent live metrics or measured model performance.
